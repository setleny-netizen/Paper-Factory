# 🏭 Бумажная фабрика

Экономический симулятор в Telegram Mini App. Аналог игры «Bitcoin mining», переработанный под бумажную фабрику.

## 🎮 Суть игры

Игрок управляет бумажной фабрикой:
- покупает **станки** (6 видов)
- ставит их на **стеллажи** (9 видов, до 6 стеллажей по 9 мест)
- снабжает фабрику **сырьём** (целлюлоза) и **электроэнергией**
- собирает **рулоны туалетной бумаги** 🧻
- соревнуется с другими в **топе** по производству

## 💰 Валюта

Рулоны туалетной бумаги 🧻. Пополнение и вывод — через API игры **Paper Scroll**.

## 🛠️ Стек

- **Frontend:** HTML, CSS, vanilla JS
- **Backend:** PHP 7.4+, MySQL
- **Интеграция:** Telegram WebApp SDK, Paper Scroll API

## 📁 Структура

- `index.html` — каркас Mini App
- `api.php` — серверная логика (все операции)
- `callback.php` — приём callback от Paper Scroll
- `assets/` — стили, скрипты, логотип
- `icons/` — SVG-иконки станков

## 🚀 Развёртывание

1. Клонировать репозиторий
2. Создать `.env` на основе `.env.example` и заполнить
3. Импортировать схему БД (`sql/schema.sql`)
4. Указать домен в Telegram BotFather
5. Готово
